# Devory

**Devory** — портфолио проект: многостраничный сайт  студии «Digital engineering», которая занимается разработкой веб-продуктов, автоматизацией бизнес-процессов, интеграциями и поддержкой. Сайт опубликован на собственном домене: **https://devory.digital**

## О проекте

Я создал Devory, чтобы на практике пройти весь путь разработки сайта: от идеи и структуры страниц до публикации на сервере. Проект показывает, как я подхожу к задачам, связанным с автоматизацией и веб-разработкой, и служит портфолио при поиске заказов и работы.

Сначала сайт был собран на Vite (статические страницы)


## Технологии

| Часть | Что использовано |
|---|---|
| Бэкенд | Python, Django 5.2 |
| Шаблоны | Шаблоны Django (общий `base.html`, подключаемые `header`, `footer`) |
| Фронтенд | HTML, CSS, JavaScript без фреймворков |
| Статика | WhiteNoise |
| База данных | SQLite |
| Сервер | VPS на Linux, nginx, ISPmanager, домен с HTTPS |
| Инструменты | Git, ESLint, Prettier |

## Что я отработал в этом проекте

- Создание и настройка Django-проекта: приложения, маршруты, шаблоны, статические файлы.
- Перенос проекта с одной технологии на другую без потери функциональности.
- Вёрстка и JavaScript: адаптивность, анимации, доступность.
- Публикация: сервер, домен, HTTPS, настройки для продакшена.

## Структура репозитория

```
backend/
└── devory/
    ├── manage.py
    ├── requirements.txt
    ├── devory/              # настройки проекта (settings, urls, wsgi)
    └── main/                # приложение сайта
        ├── templates/main/  # страницы, base.html, includes/ (header, footer)
        ├── static/main/     # CSS, JS, изображения
        ├── views.py
        └── urls.py
```

Сайт откроется по адресу http:/devory.digital
